从零搭建个人博客｜过程详解+避坑心得（附代码+截图指引）

最近花了3天时间，从零搭建了属于自己的个人博客，从环境配置到主题美化，踩了不少坑，也积累了很多实用经验。今天就把完整的搭建过程整理出来，写成一篇保姆级教学文，不管你是编程新手还是有少量基础，跟着步骤来，都能快速拥有自己的专属博客，记录生活、分享心得～

本文全程实操，包含详细步骤、配置代码、截图指引（标注了需插入图片的位置），还有我踩过的坑和避坑技巧，建议收藏慢慢看，搭建过程中遇到问题可以回头对照查找。

一、搭建前准备：明确目标+必备工具

在开始搭建前，先明确两个核心点，避免走弯路：

  • 博客用途：我的需求是记录技术心得、日常感悟，所以选择轻量、易维护的静态博客框架（无需数据库，部署简单）；
  • 核心工具：最终选择 Hexo + GitHub Pages 组合，理由是：免费、易上手、生态完善，主题丰富，适合新手。

必备环境（提前安装，缺一不可）

所有工具均为免费，安装步骤简单，跟着官方指引来即可，这里只列出必备工具和验证方法：

  1. Node.js（Hexo运行依赖）
    1. 下载地址：Node.js 官方下载（建议下载LTS版本，稳定不踩坑）；
    2. 验证是否安装成功：打开终端（Windows cmd/ Powershell，Mac 终端），输入以下代码，能显示版本号即成功：node -v ``npm -v
    3. [此处插入：Node.js安装成功后，终端显示版本号的截图，标注清楚node和npm的版本号]
  2. Git（用于部署博客到GitHub Pages）
    1. 下载地址：Git 官方下载，安装时默认下一步即可；
    2. 验证是否安装成功：终端输入以下代码，显示版本号即成功： git --version
    3. [此处插入：Git安装成功后，终端显示版本号的截图]
  3. GitHub账号（用于存放博客代码和部署）
    1. 注册地址：GitHub 官网，注册时注意用户名（后续博客地址会包含用户名，建议简洁好记）；

二、核心步骤：从零搭建Hexo博客（全程实操）

这部分是重点，每一步都有详细操作和代码，建议跟着步骤一步步来，不要跳步，避免出错。

步骤1：安装Hexo框架（终端操作）

Hexo是静态博客框架，通过命令行即可完成安装和初始化，操作非常简单：

  1. 打开终端，输入以下命令，全局安装Hexo（安装速度可能较慢，耐心等待，出现success即安装成功）： npm install -g hexo-cli
  2. 验证Hexo是否安装成功：终端输入以下代码，显示版本号即成功： hexo -v
  3. [此处插入：Hexo安装成功后，终端显示版本号的截图]

步骤2：初始化Hexo博客项目

安装完Hexo后，需要创建一个博客项目，后续所有的配置、文章都在这个项目中进行：

  1. 终端中，进入你想存放博客项目的文件夹（例如我放在桌面，命令如下）： cd Desktop # 进入桌面（Windows/Mac通用，若路径不同可自行修改）
  2. 初始化博客项目，输入以下命令（blog是项目名称，可自定义，例如myblog）： hexo init blog
  3. 初始化完成后，进入博客项目目录： cd blog
  4. 安装博客依赖包（必须执行，否则无法启动本地服务）： npm install
  5. 启动本地博客服务，预览初始效果：hexo server # 简写：hexo s
  6. 启动成功后，终端会显示“Hexo is running at http://localhost:4000/ . Press Ctrl+C to stop.”，打开浏览器，输入 http://localhost:4000，就能看到默认的Hexo博客界面了。
  7. [此处插入：本地博客默认界面的截图，标注清楚访问地址http://localhost:4000]

⚠️ 避坑提醒：如果启动服务时提示“4000端口被占用”，可以修改端口号，命令为：hexo s -p 5000（5000可替换为其他未被占用的端口）。

步骤3：配置博客基础信息（关键一步）

默认的博客信息（标题、作者、描述等）需要修改，让博客变成自己的风格，这一步需要修改项目中的配置文件。

  1. 打开博客项目文件夹（blog），找到 _config.yml 文件（这是Hexo的核心配置文件，所有基础配置都在这里）；
  2. 用记事本、VS Code等编辑器打开该文件，找到以下配置项，修改为自己的信息（注意：配置项冒号后面必须加一个空格，否则会报错，这是最容易踩的坑！）： # Site ``title: 我的个人博客 # 博客标题（例如：XXX的技术笔记） ``subtitle: 记录成长，分享美好 # 博客副标题 ``description: 专注于技术分享、日常感悟，愿我们一起成长～ # 博客描述（用于搜索引擎收录） ``author: 你的名字 # 作者名称 ``language: zh-CN # 语言（中文，无需修改） ``timezone: Asia/Shanghai # 时区（上海，无需修改）
  3. 修改完成后，保存文件，重启本地服务（先按Ctrl+C停止服务，再输入hexo s），刷新浏览器，就能看到修改后的标题和作者信息了。
  4. [此处插入：修改基础信息后，本地博客界面的截图，标注清楚修改后的标题、作者]

步骤4：更换博客主题（提升颜值）

Hexo默认主题比较简洁，我们可以更换更美观、功能更全的主题，这里推荐新手使用 Next主题（最流行、文档完善、易配置），步骤如下：

  1. 终端中，确保当前在博客项目目录（blog）下，输入以下命令，下载Next主题： git clone https://github.com/next-theme/hexo-theme-next themes/next
  2. 下载完成后，打开 _config.yml 配置文件，找到 theme 配置项，将默认的 theme: landscape 修改为 theme: next： # Extensions ``## Plugins: https://hexo.io/plugins/ ``## Themes: https://hexo.io/themes/ ``theme: next # 更换为Next主题
  3. 保存文件，重启本地服务（hexo s），刷新浏览器，就能看到Next主题的界面了（默认是简洁的白色风格，后续可以再美化）。
  4. [此处插入：Next主题默认界面的截图，标注清楚主题样式]

💡 补充：Next主题有多种风格（Muse、Mist、Pisces等），可以在主题配置文件中修改，后续会提到。

步骤5：部署博客到GitHub Pages（让别人能访问）

本地博客只能自己看到，要让别人通过网络访问，需要部署到GitHub Pages，这一步需要配置GitHub相关信息：

  1. 打开博客项目的 _config.yml 文件，找到 deploy 配置项，修改为以下内容（替换成你自己的GitHub用户名）： # Deployment ``## Docs: https://hexo.io/docs/one-command-deployment ``deploy: `` type: git `` repo: https://github.com/你的用户名/你的用户名.github.io.git # 替换成你的仓库地址 `` branch: main # 分支（默认main，若你的仓库分支是master，就改为master）
  2. 安装部署插件（必须安装，否则无法部署），终端输入：npm install hexo-deployer-git --save
  3. 生成博客静态文件（每次部署前都要执行）： hexo clean # 清理缓存（可选，但建议执行，避免旧文件干扰） ``hexo generate # 生成静态文件，简写：hexo g
  4. 部署到GitHub Pages，终端输入： hexo deploy # 简写：hexo d
  5. 部署时，会提示输入GitHub的用户名和密码（或token，若开启了二次验证，需用token登录），输入正确后，等待部署完成（终端显示“Deploy done”即成功）。
  6. 部署完成后，等待5-10分钟（GitHub需要时间同步），打开浏览器，输入 https://你的用户名.github.io，就能看到自己的博客了，别人也能通过这个地址访问！
  7. [此处插入：GitHub Pages部署成功后，浏览器访问博客的截图，标注清楚博客地址]

⚠️ 避坑提醒：1. 仓库名称必须是“用户名.github.io”，否则部署后无法访问；2. 部署时若提示“权限不足”，检查GitHub用户名和密码是否正确，或重新生成token；3. 同步时间可能需要5-10分钟，耐心等待，若仍无法访问，检查配置文件中的deploy信息是否正确。

四、搭建心得+避坑总结

整个搭建过程，从环境配置到部署成功，我踩了不少坑，也总结了一些心得，分享给大家，帮大家少走弯路：

1. 心得感悟

一开始我也是零基础，以为搭建博客很难，实际操作后发现，只要跟着步骤来，每一步都仔细看，其实很简单。搭建博客的过程，不仅学会了Hexo和GitHub的基本使用，还锻炼了自己的动手能力，当看到自己的博客能被别人访问时，那种成就感真的很棒～

另外，个人博客不仅是记录和分享的平台，也是自己成长的见证，后续可以慢慢优化，添加更多功能（比如评论、访客统计等），让博客变得更有个性。

2. 常见坑及避坑技巧

  • 坑1：配置文件 _config.yml 冒号后没加空格，导致博客启动失败。 避坑：修改配置时，所有冒号后面都必须加一个空格（比如 title: 我的博客，不能写成 title:我的博客）。
  • 坑2：部署后无法访问，提示404。 避坑：检查仓库名称是否为“用户名.github.io”，deploy配置中的仓库地址是否正确，分支是否为main（或master）。
  • 坑3：图片部署后无法加载。 避坑：不要使用本地绝对路径，用相对路径（source/images目录）或图床链接。
  • 坑4：启动服务时端口被占用。 避坑：用 hexo s -p 端口号 更换端口，比如 hexo s -p 5000。

五、总结

以上就是从零搭建个人博客的完整过程，从准备工作、环境配置，到搭建、部署、美化，每一步都有详细的操作和代码，还有我踩过的坑和心得。

其实搭建博客真的没有那么难，新手也能快速上手，关键是要有耐心，一步一步来，遇到问题不要慌，多查资料、多尝试，总能解决。

如果你也想拥有自己的个人博客，不妨跟着这篇教程动手试试，相信你也能顺利搭建出属于自己的博客，记录生活、分享成长～
